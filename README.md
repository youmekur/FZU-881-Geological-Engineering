# 881《地质工程概论》v1.6 教学资源公开共享包

本包包含完整62单元Markdown讲义、10幅高清PNG及对应的可编辑SVG。讲义图片使用相对路径 `高清PNG/文件名.png`，请保持目录结构。

## 资料性质

本资料是依据福州大学2027年881考试大纲、舒良树《普通地质学》第四版和唐辉明《工程地质学基础》第二版整理的考研辅助教学资源，不是学校、教材作者或出版社发布的官方版本，也不替代指定教材。专业教师审校和真实学生教学验证尚未完成。

## 图示与显示

Markdown默认显示高清PNG；对应SVG供编辑使用。SVG纹理已嵌入，不依赖外部素材。SVG中文标注保留为文本对象，并设置常见中文字体和回退字体。当前检查环境缺少合适的中文字体，故本机Inkscape预览中文字形显示不完整；对应PNG标注显示正常。建议在安装CJK字体的系统或编辑器中打开SVG。
